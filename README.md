# EXO-ISO analysis code and AK1 docking

This repository contains the analysis code accompanying the manuscript and Supporting Information, together with the docking package. Non-docking input datasets are supplied with the article's supplementary files. 

## Obtain and place the inputs

Download `Input_Source_Files.zip` from the article's supplementary files. Extract its contents directly into the downloaded repository root, preserving the folder names. After extraction, the following folders must exist:

```text
Input_Source_Files/
```

`Input_Source_Files` contains the TAC expression/comparison exports and GO/MSigDB reference files used by the included analyses. Figure S6 uses the sample-level scores generated by Hallmark_ssGSEA [Figure3c] so create chapter 05's `Inputs` folder and copy `ssGSEA_Hallmark_scores.csv` into it.

## Software and execution

The R analyses were tested with R 4.6.0 on Windows. Open R or RStudio and run:

```r
source(file.choose(), encoding = "UTF-8")
```

Select the method TXT. These TXT files in chapters 01-05 contain executable R code. Some scripts open a second picker: select `Input_Source_Files/All Expressions.txt`, or the specific preceding-step output requested. Preserve the repository folder layout. Each method's header lists its inputs, outputs, packages and run instructions.

Install required packages before running. CRAN dependencies include ggplot2, dplyr, tidyr, tibble, readr, readxl, openxlsx, ggrepel, patchwork, msigdbr, circlize, igraph, ggraph, ragg, magick, httr and jsonlite where used. Bioconductor dependencies include limma, GSVA, ComplexHeatmap, AnnotationDbi, org.Hs.eg.db and GO.db where used. The source files are authoritative for each method's dependency list. Use `install.packages()` for CRAN and `BiocManager::install()` for Bioconductor packages, in the same R installation used to run the code.

Missing packages should be installed. R packages built for a different patch version can emit warnings. Figure generation requires working PNG and Cairo PDF devices. Internet access is required for live KEA3 queries and for reference downloads not already cached locally.

## Methods, figures and run order

| Folder | Figures | Order and purpose |
|---|---|---|
| 01_Differential_Expression_and_Hallmark_ssGSEA | 3a-f | Run Exact_ID_DEGs_GO and Hallmark_ssGSEA. |
| 02_Pathway_Gene_Recurrence | 4, S4.1-S4.2 | Run the main recurrence method, then the full ranked supplementary method. |
| 03_ROAST_Gene_Set_Testing | 5 | Run the ROAST script with the supplementary expression/reference inputs. |
| 04_Signaling_DEG_KEA3_Figure6_S8_S9 | 6, S8-S9 | Run the five scripts in numeric filename order. Later scripts consume earlier outputs. |
| 05_Hallmark_Pathway_Correlation_Networks | S6 | Run Hallmark_ssGSEA in chapter 01 first. Copy its generated `ssGSEA_Hallmark_scores.csv` into this method's `Inputs` folder before running. |
| 06_AK1_Docking_and_Sensitivity | 8, S13-S19 | Follow this folder's `README.txt` to prepare an independent working copy, then the chapter instructions. |

Outputs are written to method-specific result directories described in the code. For chapter 05, the default is the method's `Results` folder. Scripts may replace their own generated outputs when rerun. Use an independent copy for verification.
