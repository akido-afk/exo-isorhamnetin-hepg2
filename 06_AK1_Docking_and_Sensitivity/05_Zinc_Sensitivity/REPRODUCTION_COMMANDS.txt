RECOMMENDED REPRODUCTION STEPS

Run these commands from the working project's structures/ directory after completing the setup in the docking README. The optional new-search sections run new docking calculations.

ZN601 INPUT PREPARATION
Prepared ZN601 receptor inputs are supplied. To rebuild in an independent working copy:
python ..\run_analysis.py build_AK1_FIXED_ZN601.py
python "%CONDA_PREFIX%\Lib\site-packages\meeko\cli\mk_prepare_receptor.py" --read_pdb "..\receptors\AK1_chainA_FIXED_ZN601.pdb" -o "..\receptors\AK1_ZN601" -p

OPTIONAL NEW SEARCH (prepare with --fresh-docking)
python ..\run_analysis.py --allow-docking run_AK1_ZN601_10seeds.bat

ANALYSIS FROM SAVED OR NEW POSES
python ..\run_analysis.py AK1_ZN601_10seed_comprehensive.py
python ..\run_analysis.py AK1_panelI_ZN601_sensitivity.R
