02 AP5 Redocking and Validation
RECOMMENDED REPRODUCTION STEPS

Run these commands from the working project's structures/ directory after completing the setup in the docking README. The optional new-search sections run new docking calculations.

AP5 POSE VALIDATION
Use the saved AP5 SDF and native AP5 inputs to calculate RMSDs:
python ..\run_analysis.py calc_AP5_RMSD.py

OPTIONAL COMPLETE AP5 REDOCKING
Prepare the working copy with --fresh-docking before these commands. Activate the docking conda environment and work from structures/.
python "%CONDA_PREFIX%\Lib\site-packages\meeko\cli\mk_prepare_ligand.py" -i "..\ligand\AP5_ideal.sdf" -o "..\ligand\AP5.pdbqt"
set "VINA=..\software\vina_win.exe"
"%VINA%" --receptor "..\receptors\AK1.pdbqt" --ligand "..\ligand\AP5.pdbqt" --center_x 25.044 --center_y 44.571 --center_z -3.708 --size_x 23.687 --size_y 23.364 --size_z 30.062 --exhaustiveness 16 --num_modes 10 --seed 1001 --out "..\docking\AK1_AP5_redock_seed1001.pdbqt"
python "%CONDA_PREFIX%\Lib\site-packages\meeko\cli\mk_export.py" "..\docking\AK1_AP5_redock_seed1001.pdbqt" -s "..\docking\AK1_AP5_redock_seed1001.sdf"
python ..\run_analysis.py calc_AP5_RMSD.py

The separate AP5 ten-seed score-context searches use:
python ..\run_analysis.py --allow-docking run_AK1_AP5_10seeds.bat
python ..\run_analysis.py AK1_AP5_vs_ISO_score_comparison.R
